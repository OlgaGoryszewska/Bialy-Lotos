# Biały Lotos

Biały Lotos is a full website build for a beauty and cosmetology salon — permanent makeup, laser treatments, brows, lashes, skincare. I designed the brand identity and built a fast, content-driven Next.js site: 15+ dynamic treatment pages, a searchable price list, a before/after gallery, and problem-based navigation that guides visitors from a concern to the right treatment and booking link. Added GDPR-compliant consent handling and connected every service to Booksy booking. Built with React, Tailwind CSS, and Jest, deployed on Vercel — a fast, SEO-ready site that turns visitors into bookings.

## Features

- Dynamic treatment pages generated from structured service data
- Problem-based navigation connecting client concerns to recommended treatments
- Searchable, expandable price list across PMU, cosmetology, laser, and piercing
- Before/after gallery organized by treatment category
- GDPR-compliant, consent-gated Google Maps embed
- Booksy-connected booking flow on every treatment and voucher
- Responsive layout with a sticky nav and mobile menu

## Tech Stack

Next.js · React · Tailwind CSS · Jest · React Testing Library · ESLint · Prettier · Vercel

## Scripts

```bash
npm run dev      # start the dev server
npm run build    # production build
npm run start    # serve the production build
npm run test     # run the test suite
npm run lint     # lint the codebase
npm run format   # format with Prettier
```
